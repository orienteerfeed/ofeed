# IOF control description symbols

SVG symbols for the IOF 2018 Control Description Standard, used by the thermal-printer
control description generator (`src/pages/Utils/ControlDescriptions`).

Source: https://github.com/petergolde/IOF2018-ControlDescriptions — released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) (public domain,
no attribution required). The images are identical to those used by Purple Pen.

The filename's first space-delimited token is the symbol reference and is the lookup key
(`0.1E Eastern.svg` → `0.1E`). Purple Pen `.ppen` files store IOF **2004** references,
which differ from these 2018 filenames for columns G and H — see `iofSymbols.ts` for the
mapping table.

The upstream set corresponds to a pre-release IOF draft and will need refreshing when
the IOF publishes the final standard.
